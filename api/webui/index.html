RuleCraft

Windows 轻量级自动化规则引擎

版本： 1.0.0

运行端口： 19530

内置输入插件： 30+

内置输出插件： 20+

技术栈： Go + 原生 Win32 API + 嵌入式 Web UI

RuleCraft 是一个轻量级的 Windows 自动化规则引擎，通过条件-动作（Condition-Action）模式实现系统自动化。支持多种输入传感器和输出执行器，提供 Web 管理界面进行规则配置。

本项目为开源项目，遵循 MIT 许可证。
